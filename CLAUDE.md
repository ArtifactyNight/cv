## Design Context

This is a **brand-register** personal portfolio and blog (Astro + Tailwind v4). Strategic and visual specs live at the project root:

- **PRODUCT.md** — users (peers/builders), purpose, voice (precise · quiet · opinionated), anti-references, principles
- **DESIGN.md** — visual system ("The Margin Note": narrow column, committed ink-blue accent, flat surfaces, Satoshi + IBM Plex Sans Thai)

v1 priority: a strong **home/profile page** with intro → work → writing structure (reference: [designerdada.com](https://www.designerdada.com/)).

Use `/impeccable` commands for design work; live mode is configured at `.impeccable/live/config.json`.
